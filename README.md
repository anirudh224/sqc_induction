## About the Project

This repository contains the official **induction website** for **Super Quant Coders** — a high-performance quantitative coding & algorithmic trading club.

The site was launched live on **Induction Day 2026** to welcome new members, showcase the core team, explain the unique **robotic dog achievement ranks**, and celebrate everyone's participation.

**Live Demo:**  
https://anirudh224.github.io/sqc_induction/

<br/>

## Key Features

- Futuristic neon cyberpunk design
- Responsive member cards with modal profiles
- Robotic dog achievement tiers & unlock visualization
- Induction Day welcome message & thank-you banner
- Clean separation: HTML + CSS + JavaScript
